# untitled-bots

## Неофициальный репозиторий ботов для UntitledAI

Репозиторий сделан с разрешения создателя, так что я ничего не нарушаю.
Здесь хранятся боты для РП для приложения UntitledAI — как мои, так и ваши.

## Формат

Все боты хранятся в отдельных `.json` файлах. Они содержат информацию
для вставки в приложение.

## Как использовать бота

Сейчас в приложении нет возможности добавления пользовательских
репозиториев, поэтому:

1. Открываете приложение
2. Три точки → импорт бота (JSON)
3. Вставляете код бота

## Как добавить своего бота в этот репозиторий

Отправляйте своих ботов мне в Telegram: [@hereip](https://t.me/hereip)
